# 工号录入与图库自动刷新

录入界面只接受 1 至 20 位数字工号，并保持前导零。新人员必须输入姓名；已有工号会复用数据库中的姓名，只追加一个人脸样本，不会创建第二个身份。姓名输入支持英文/拼音和数字。

## 一致性规则

保存或删除样本时，GUI 线程先重新读取 SQLite 样本快照，递增图库版本，再由推理线程重建参考特征。版本不匹配的旧推理结果不能确认身份或写入考勤。读取失败时，程序每五秒重试；不能完成对齐或特征提取的样本会在终端输出 `Reference rejected`。当前原型要求至少两个有效人员，才会进行身份确认。

## 验证步骤

1. 单人正对摄像头，确认“录入人员”按钮可用。
2. 选择“编辑工号”，输入一个已经存在的纯数字工号，例如 `001`，确认界面提示这是追加样本而非新建人员。
3. 确认追加，观察日志出现新的 `Gallery ready`。人员数应不变，样本数增加。
4. 在管理菜单删除刚新增的样本，观察图库再次刷新，原人员和历史考勤保持不变。
5. 取消输入、删除确认或键盘输入时，不应产生数据库写入。

## 部署前提

此仓库不携带数据库或样本。请仅在拥有授权的目标设备上操作实际人员数据，并在修改生产程序前备份 `data/attendance.db`。对应用代码做行为改动后，再在目标板运行 `qmake face_attendance.pro -o Makefile`、`make -j2` 和完整现场验收。

Windows 本地可运行 SQL 与纯 C++ 回归测试；Qt/RKNN、摄像头、触摸布局仍必须在目标板验证。详见 [TESTING.md](TESTING.md) 和 [FINAL_ACCEPTANCE.md](FINAL_ACCEPTANCE.md)。
